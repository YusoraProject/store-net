# 计费规则配置

进入“门店管理 → 计费区域 → 编辑”。只有一个区域时，也可在下面的“定价”页编辑同一份规则。定价仅允许有相应权限的管理员或本店店长修改。

## 自定义时段

每个区域可设置1至24个时段，自定义名称、开始时间、结束时间、每小时价格和每日该时段封顶价。

- 时段必须覆盖完整24小时，不能重叠或留空。
- 时间精确到分钟，使用00:00至23:59。结束早于开始表示跨午夜，例如22:00至08:00；起止相同表示全天，只能保留这一个时段。
- “添加时段”平分最长时段并复制价格；可随后改名、调整时间和价格。“删除时段”会将时间合并到前一个相邻时段，沿用前一时段价格。
- 封顶价为0表示不限额。封顶按计费时区的每个自然日、每个时段分别计算，跨午夜在零点重开当天封顶。
- 分段分钟数向上取整，金额以整数分计算。与旧规则一样，跨时段和换区会分别计算对应段的分钟数。

## 周末、节假日与特殊日期

“周末单独计价”开启时，周六、周日使用周末价格；关闭时使用基础价格。

“节假日单独计价”开启时，手动添加的节假日和特殊节假日规则生效。关闭时忽略这两类规则，回到基础或周末价格；已填的节假日价格和日期配置仍会保留。此开关不会关闭周末计价或调休工作日规则。

“添加日期规则”可填写名称、开始日期、结束日期及计价方式。日期范围包含首尾两天，规则之间不能重叠。

| 计价方式 | 行为 |
| --- | --- |
| 节假日价格 | 该日期范围使用每个时段的节假日费率 |
| 特殊节假日单独定价 | 为该范围的每个时段分别填写小时价和封顶价 |
| 基础价格（调休工作日） | 将该日期范围按基础价格计算，即使当天是周末 |
| 周末价格 | 将该日期范围按周末价格计算；周末开关关闭则使用基础价格 |

日期规则优先于通常的星期判断。例如把10月1日至7日设为“国庆 · 特殊节假日单独定价”，再为日间和夜间设置不同收费。规则按具体年份保存，不自动重复到下一年，也不自动下载中国法定节假日或调休安排。

## 时区与历史消费

当前配置及新开始的计费段固定按北京时间（UTC+8）判断时段、日期与周末，页面不再显示或提供时区切换。

旧版本已开始的消费保留原时区快照，不追溯改价。旧区域之后新开始上机或换入时，统一生成北京时间规则快照。

开始上机和进入新区时保存规则快照，包含时段、费率、日期规则、开关与固定时区。修改配置不会重算已开始的计费段；同店换区后新段使用目标区域当时的规则。回到同一区域且规则未变，仍共享当天该时段封顶。旧快照若仅转换格式而实际规则不变，也不会重置封顶；UTC 与 UTC+8 属于不同有效规则。

数据库表结构不变，无需清空本地数据库。会员选区时可以查看当前时段价格与已生效的特殊日期规则。
