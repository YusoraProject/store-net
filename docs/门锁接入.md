# 通通锁接入说明

## 当前进度

管理端已实现授权配置、连接测试、门锁绑定、手动生成一次性密码、查询创建记录、核对结果和查看密码审计。相关流程目前只经过模拟测试，没有完成真实门锁开门验收。

**会员上机自动发码和区域计费已接入。** 先保存区域并绑定门锁，再在HTTPS下启用自动发码。会员选择区域，密码确认成功后才开始计时；店长代上机遵守相同规则。普通区域不发码，但同样只能有一条进行中的会话。

店长需要有门店管理权限，并且是该门店的有效店长；管理员可以操作全部门店。普通会员不能查看管理端密码和凭证。

## 需要准备什么

- 通通锁开放平台应用编号和应用密钥。
- 拥有目标门锁权限的通通锁 App 账号及密码，不是开放平台登录账号。
- 对应的服务区域。目前接入中国和欧洲地址。
- 支持第四版密码的门锁。
- HTTPS 访问地址，以及本项目独立的门锁加密主密钥。

账号密码只用于本次授权，不保存到数据库。应用密钥、访问令牌和刷新令牌均加密保存。开启真实调用后，后台每30秒检查一次，在到期前5分钟内尝试自动续期；管理页可以查看到期时间、续期状态，也可以点击“检查授权续期”。授权还充足时不会重复刷新。

续期采用[通通锁官方刷新接口](https://euopen.ttlock.com/doc/oauth2/refreshToken)，一起保存返回的新访问令牌和刷新令牌。数据库租约保证同一门店同一时间只有一个进程续期，网络等待期间不会锁住业务数据库。续期不改变门店的账号授权版本，因此原发码申请仍可用新令牌核对。

续期请求超时、保存失败或进程中断时，系统无法保证旧刷新令牌还能重用，会标记“需人工处理”，不会盲目重放。此时需要重新授权；如还有未决发码申请，先由店长核对或确认风险后取消，不能直接换账号。续期结果不明时自动发码会暂停，不会跳过门锁流程直接计费。

## 配置时注意

`TTLOCK_REAL_ENABLED` 默认关闭。仅在完成部署检查并准备好受控测试门锁后才考虑启用；不要在日常营业门锁上直接试代码。

`TTLOCK_MASTER_KEY` 是随机 32 字节密钥的 Base64 编码，不是通通锁应用密钥。两个项目不能共用。密钥丢失后，数据库中的加密凭证和密码无法解密，因此需要独立、安全地备份。

授权、门锁列表和密码操作要求 HTTPS，本地 HTTP 也不能录入真实凭证。配置反向代理时只信任已知代理，不接受客户端任意伪造的协议头。

## 手动发码

选择门店，配置授权并通过连接测试，再在区域上绑定门锁。手动发码不创建消费，也不扣费。

创建成功只代表通通锁返回了密码，不代表有人已经开门。一次性密码使用实际返回的有效时间，不承诺从点击按钮开始完整有效六小时。

记录列表不返回密码明文。查看密码会留下审计记录，请只交给应当进入该区域的人。

## 结果不确定时

如果请求超时、网络断开或本地保存失败，门锁端仍可能已经生成密码。此时先查看原记录并核对，不要不断新建请求。

未核对到记录不能证明原密码不存在。存在待确认请求时，系统会阻止更换授权，避免失去核对原账号的条件。当前没有自动撤销、远程开门或密码已使用状态同步，不要把结账理解为门锁密码自动失效。

## 上机和换区

上机入口已接入数据库占用约束；结账成功才释放。价格在上机时保存，不跟随之后的改价变化。启用真实调用时，后台每30秒检查近期申请，尝试核对最近5分钟内的未决请求；超过窗口后由店长手动核对。失去响应的旧进程只能核对结果，不能重新发码。

同店换区保留消费单，不立即扣款。每次停留单独记录进入、离开时间及价格快照，结账时汇总。返回同一区域且价格快照相同时，沿用当天日间、夜间各自的封顶，不因换出再换入重置。每个计费时段按分钟向上取整；不同价格快照分别封顶。次卡暂时沿用整笔消费扣一次的现有规则。

开启自动发码的目标区域，确认密码成功后才切换计时；失败或待确认期间继续计算原区域费用。待确认时不能继续换区或结账，先核对结果，或由店长确认风险后取消申请。取消换区申请不会结束原消费，也不会撤销可能已经产生的门锁密码。跨门店仍需先结账。

会员刷新后可恢复待处理状态，在当前消费中查看当前区域的入场密码。确实无法确认时，店长可在明确知晓原密码可能仍有效的前提下取消申请；上机申请取消后不开始计费，换区申请取消后仍留在原区计费。

## 首次运行

本项目目前按尚未部署准备。首次启动后端时，门锁、区域、发码记录和授权续期表会与普通业务表一起创建，不需要单独安装数据库模块，也不会复制旧消费或旧门锁授权。先启动项目、创建门店，再进入管理端配置门锁即可。

真实门锁默认关闭，旧数据库和旧密钥不会自动导入。遇到结构不兼容的数据库时，程序会停止并提示检查配置，不会自动修改原表。详细启动步骤见[本地运行与配置](本地运行与配置.md)。

仍需补充跨进程限流，以及实际数据库副本、MySQL、HTTPS和真实测试门锁验收。授权续期已经过模拟测试，但这不代替真实账号与测试门锁验收。
