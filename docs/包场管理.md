# 包场管理

## 店长配置

- 门店管理 → 定价 → 包场时段与价格：添加时段名称、区域或整店、起止时间、总价及开放开关。起止相同表示24小时，结束早于开始表示跨午夜。时段允许作为不同套餐重叠配置，实际预约必须无冲突。
- 门店管理 → 包场 → 包场配置：设置订金比例，范围1%至100%，默认30%。订金按整数分向上取整。包场总价和订金比例在订单创建时固定，调价不会修改已有订单。
- 时段定价需要该门店定价管理权限；订金、手动创建、线下收款及退款需要该门店消费管理权限。

## 会员预约与邀请

1. 在主导航“包场”选择门店、日期和开放时段，创建预约。价格由服务器按配置确定，会员不能修改总价。
2. 未付款预约保留15分钟，或直到时段结束，以较早者为准。超时释放时段，不能继续支付原订单，需要重新预约。
3. 发起人确认从该门店充值余额扣除订金。赠送余额和次卡不用于订金。余额不足时不扣款、不开放邀请。当前未接入微信或支付宝支付。
4. 支付成功后可搜索本店会员，发送邀请；受邀人在自己的“包场”页面主动同意或拒绝。邀请不向其他渠道发送通知。未同意、拒绝、非参与会员均无免费上机资格。
5. 仅在预约的区域和时段内，付订金的发起人及已同意的有效会员可以使用“包场免费上机”。结束免费上机不扣充值余额、赠送余额或次卡。退出邀请、店长取消包场或时段到期时，免费会话结束。

## 手动创建和收退款

店长可选预设时段，或自定义起止时间与总价；可选择发起用户和受邀用户。发起人自动加入，受邀人仍须主动同意。支付订金前邀请不可接受、参与者不能免费上机。手动订单立即预留时段，不受会员订单15分钟未付超时限制。

发起人可用充值余额付订金，也可由店长收到线下款后“登记订金”。剩余尾款由店长线下收取并“登记尾款”，也可一次登记全款。重复支付和重复登记不会重复入账。

未付订金的发起人可以取消；已付款订单需联系店长处理。店长取消时，充值余额支付部分自动退回原会员在该店的充值余额，线下实收部分须在线下退还后再确认。退款和取消在同一事务中完成，保留原订单、支付、操作人和权益流水。当前采用全额退款；修改安排请取消后重建。

门店累计营收包含包场实收减退款。包场订金和余额退款进入权益流水；免费上机显示为“包场免费”，金额为0，不重复计入包场收入。

## 上机与时间边界

时间固定按北京时间（UTC+8）输入和显示，数据库仍统一存UTC；界面不显示时区设置和设备时区说明。

包场区域显示提示并禁用普通上机。后端在开始上机、换区、自动发码预占与成功确认时再次校验资格，绕过页面也不能取得免费权益。免费会话不能换出包场范围；普通会话须先结账才能转为包场免费会话。整店包场覆盖后续新增的区域。

未来预约前仍可正常营业；开始前店长须清场并结清非参与者的普通消费，系统不会擅自结束或改价普通消费。预约当前时段时，已有上机或待确认发码需先处理。免费会话到期在后台每30秒回收，读取当前会话或再次上机也会回收；结束时间始终截到预约结束，不会产生时段外费用。

自动发码区域沿用现有通通锁流程，远端确认之前不开始上机。预约或邀请失效时不允许把原免费发码请求转成付费会话。既有门锁密码不会因包场取消自动撤销，门店仍需按实际情况管理现场入场。

## 数据兼容

新增或补建 `venue_bookings`、`booking_settings`、`booking_details`、`booking_invitations`、`booking_sessions` 表。初始化先验证全部已有表，再仅补建允许的缺失包场表；不修改旧表或既有消费快照。旧手动包场记录可继续查看、收款和退款。
